# Notecode

メモ帳の軽さ、モダンエディタの書き心地。Windows / macOS 向けの軽量テキストエディタです。

- サイト: https://notecode.click/
- ダウンロード: [Releases](https://github.com/keta467-releases/notecode/releases/latest)
- バグ報告・機能リクエスト: [Issues](https://github.com/keta467-releases/notecode/issues/new)

このリポジトリは配布物（インストーラーと自動更新用ファイル）とサイトの置き場です。
